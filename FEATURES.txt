MAPLE JOURNAL — Feature list
Updated October 20, 2026

1. Session history and map comparison
Save completed sessions with map, class, starting/ending level, active time, and results. Filter history by class and starting-level range. Compare maps using total gains divided by total active time so short runs do not skew averages. Export/import JSON backups and export CSV.

2. EXP versus profit
Plot each map's EXP/hour against net mesos/hour. Choose original net, adjusted cash net, or estimated net including unsold loot. Show the fastest training map and highest-profit map for the selected history.

3. Leveling estimates and projections
Estimate time to the next level or a chosen target using the completed session’s final pace. Show projected EXP and original-formula net mesos for 30 and 60 active minutes. Label estimates and handle zero/negative EXP pace.

4. Potion efficiency
Show HP/MP items consumed per minute, total supply cost per hour, and potion spending as a percentage of positive meso balance change.

5. Supply runway
Estimate remaining HP and MP training time at the observed usage rate. Distinguish empty supplies from a supply that has no recorded consumption.

6. Checkpoints and pace trends
Record level, EXP, mesos, supplies remaining, and cumulative additions while training. Offer an inline reminder every 10 active minutes. Compare consecutive intervals in a table and chart. Measurements are manual snapshots, not a live game connection.

7. Loot and expense ledger
Track estimated unsold loot, income not yet in the entered balance, and expenses not yet in the entered balance. Keep the requested original net formula unchanged. Present adjusted cash and estimated loot-inclusive totals separately. Never add a sale or expense twice if already reflected in the ending balance.

8. Automatic level-up handling
Use starting/ending levels plus within-level EXP to calculate gains across one or more levels. Use MeowDB Classic formulas for levels 1–99 and level 100 as the table endpoint. Preserve manual extra-EXP adjustment for older sessions without level metadata.

9. Pause/resume
Exclude breaks from every rate and estimate. Show active and wall time, preserve pauses through refresh, and allow Done while paused.

Existing features retained
Start/Done flow, EXP and original-formula mesos per hour/10 minutes/minute, editable MeowDB supplies including Meat/Lemon, custom supply prices, negative gains, refresh recovery, light/dark slider, sun/moon icons, and a standalone HTML copy.

Data and calculation notes
History, drafts, theme, and checkpoints are stored in the current browser only. Local files and the hosted website use separate browser storage. Back up important history. Compare runs of similar level/class/buffs/party conditions; the tool does not normalize game conditions.
Original net = ending mesos - starting mesos - HP used * HP unit price - MP used * MP unit price.
Adjusted cash net = original net + uncounted income - uncounted expenses.
Estimated total net = adjusted cash net + estimated unsold loot.
Supply used = starting + cumulative additions - remaining.
Source: https://meowdb.com/msclassic/formulas/leveling

Layout: timer and inputs use one aligned stack. Current-session results, forecasts, supply insights, and checkpoint trends appear only after Done, ending values, and Calculate. Editing or starting a new session hides that review again. Prior completed sessions stay available in history; an empty map-comparison panel is hidden.

Navigation: Session tracker contains the current timer, forms, and completed-session review. History & comparison is a separate tab containing saved runs, review details, filters, backups, and map comparisons. Switching tabs preserves the tracker draft and does not pause a running session. The selected tab is retained in the URL fragment across refresh.

ETC vendor loot: local searchable icon/name/price catalog; quantities, merged additions, editable sale status, vendor subtotal, saved price snapshots, history review, JSON restore, and CSV summary. Main result rates can include unsold vendor estimates while preserving original cash net.

Screenshot import: on-device recognition of map, job, level, EXP and mesos; automatic HP/MP count proposals with user-selected items; capture guide; per-field adjustable regions; local layout memory; editable opt-in review; starting/ending integration; cancellation and embedded standalone runtime. ETC stays manual.
OCR tuning: per-field text-color presets, contrast/brightness/threshold/color-tolerance controls, 2–6x bounded enlargement, inversion, exact processed preview, targeted reread with segmentation alternatives, preservation of other reviewed fields, selectable alternate readings, local setting memory, and field/all resets. Small quantity digits still require review.
Potion selectors: local MeowDB icons for all 13 named supplies, icon/name/price choices in setup and OCR review, generic custom-item marker, keyboard navigation/type-ahead, session-state locking, and embedded standalone icons. Prices and calculations are preserved.

Classic potion digit matching defaults for HP/MP; original-color local worker, general OCR fallback selector, conservative blank on ambiguous font matches, offline embedded dataset.

Training-map OCR matches both readings to an offline MeowDB map catalog; up to two canonical suggestions, searchable corrections, uncertain matches require choice, invalid OCR labels cannot be applied.

Direct browser screenshot capture alongside file upload. Choose a monitor once and reuse it for later snapshots while the page stays open, including between starting and ending imports. Visible sharing status, Stop sharing inside/outside the dialog, Change source, no audio/recording, pending-request cancellation, automatic page-exit/source-end cleanup, and upload fallback.

EXP screenshot recognition: dedicated local status-bar font matcher with scaled/antialiased fitting, commas, green-bracket percentage exclusion, zero support, conservative unclear/cut/obscured digit rejection, selectable General text OCR, cancellable worker and offline/standalone support.

Recognition reader is visible for every screenshot preset; all five numeric fields can choose either Classic digit template or general OCR. Text fields explain why digit-only templates are unavailable. Saved reader choices and color settings are independent per field, with legacy setting migration.

Automatic progress: opt-in full-screen snapshots once a minute while running; five numeric fields read locally, per-field settings reused, pending validation delay, outlier/quality gates, manual restock rebase, actual capture timestamps, bounded jobs, pause/stop lifecycle, value-only decision log and confirmed checkpoints in history. Reported window/tab sources are rejected; browsers without source-type metadata require users to choose a full screen. Final totals remain reviewed.

Live training dashboard replaces the running input form: two capture-time session-average rate charts, provisional/confirmed markers, gain/profit/supply/ETA stats, optional mesos with honest N/A gaps, independent mesos validation, and partial confirmed progress in drafts/history/JSON. Initial form defaults to automatic capture after validation.

Stats/Graphs/Combined layouts, selected EXP/net-mesos metrics, optional active time, opacity and text-size controls. Confirmed readings only; per-run opt-in; retained final summary; hide/reset; separate read/publish credentials; one-tab lease; bounded latest graph; local-only token hashes and latest snapshot; no hosted relay or cloud session storage.
